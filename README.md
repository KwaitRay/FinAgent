# finagent

单文件金融智能体可视化展示。下载并直接打开 [index.html](index.html)，无需安装、构建或网络依赖。

## 内容

- 系统总览：完整架构与九阶段半导体研究回放。
- 诉求与评测：分类发现、二级诉求与对象标签，四类案例的规划及过程／结果准则，交互评分与强化学习衔接，标注校准与评测集边界。
- 监督微调：三类轨迹、角色与监督掩码、思考质量及数据隔离。
- 强化学习：交互评分、未来回报、四类优势比较和裁剪策略目标。
- 工具系统：四层能力、按状态重排、工具关系与技能演进。

使用页内导航切换模块，也可通过 #overview、#evaluation、#sft、#rl、#tools 定位。所有样式、脚本与图形都在同一个 HTML 文件内。

## 数据口径

项目配置来自项目访谈记录。案例、分数与更新计算为教学演示，不代表实测收益或当前金融事实。Tree-GRPO 使用独立固定算例；默认优势仅中心化，其他示例可切换样本标准差归一化。策略更新部分展示裁剪代理目标，不执行真实训练。

## 托管

可由任意静态服务器提供。若启用 GitHub Pages，将 main 分支根目录设为发布目录即可；仓库推送本身不代表 Pages 已启用。
